## Final project highlight

The final project investigates whether a learner can infer which peer is strongest and use that peer’s policy to improve learning in `LunarLander-v2`. It combines Double DQN, REINFORCE with a baseline, neural policy estimation, KL regularization, and a Step-Wise Mapped Reward (SWMR) score. The final repository includes the [proposal](https://github.com/HanifGanji/il-final-project-social-learning/blob/main/paper/proposal.pdf), [final report](https://github.com/HanifGanji/il-final-project-social-learning/blob/main/paper/final-report.pdf), presentation, saved plots, checkpoints, and rollout videos.

## About the archive

These repositories preserve coursework completed during Fall 2024 and finalized in early 2025. Notebooks retain their outputs where that makes the experiments easier to review. Virtual environments, duplicate archives, caches, and incomplete folders were intentionally left out.

The code in each repository is released under the MIT License. Reports, presentations, plots, checkpoints, and videos remain coursework artifacts by their listed authors.
